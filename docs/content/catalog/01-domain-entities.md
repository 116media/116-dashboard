# Phase 1: Domain Entities

Entity interfaces for the 3 catalog resources and their nested value objects.

**Module path:** `src/modules/catalog/domain/entities/`

---

## `ICategoryPricingEntity.ts`

```ts
interface ICategoryPricingEntity {
    id: string;
    categoryId: string;
    pricingTierId: string;
    tierName: string;
    priceUsd: number;
}
```

Maps from backend `CategoryPricingDto`. Nested inside `ICategoryEntity.pricing[]`.

---

## `ICategoryEntity.ts`

```ts
interface ICategoryEntity {
    id: string;
    contentTypeId: string;
    contentTypeName: string;
    name: string;
    slug: string;
    description: string;
    isFree: boolean;
    isActive: boolean;
    pricing: ICategoryPricingEntity[];
}
```

Maps from backend `CategoryDto`. `slug` is auto-generated by the backend from `name`. `pricing` may be empty when a category is free (`isFree: true`).

---

## `ICustomerEntity.ts`

```ts
interface ICustomerEntity {
    id: string;
    fullName: string;
    email: string;
    phone?: string | null;
    company?: string | null;
    notes?: string | null;
    createdAt?: string | null;
    updatedAt?: string | null;
    createdBy?: string | null;
    updatedBy?: string | null;
}
```

Maps from backend `CustomerDto` which includes auditable fields.

---

## `IPackageSlotEntity.ts`

```ts
interface IPackageSlotEntity {
    id: string;
    packageId: string;
    categoryId: string;
    categoryName: string;
    isRequired: boolean;
    quantity: number;
}
```

Maps from backend `PackageSlotDto`. Nested inside `IPackageEntity.slots[]`.

---

## `IPackageEntity.ts`

```ts
interface IPackageEntity {
    id: string;
    name: string;
    description?: string | null;
    flatPriceUsd: number;
    isActive: boolean;
    slots: IPackageSlotEntity[];
    createdAt?: string | null;
    updatedAt?: string | null;
    createdBy?: string | null;
    updatedBy?: string | null;
}
```

Maps from backend `PackageDto` which includes auditable fields. `slots` lists which categories are included in the bundle and whether each is required.
